# docx 结构：节、封面、域与页眉页脚

## 页面与节

两版的节数与回归基线见 [验证清单](60-validation.md)。研究生版依次排中英文封面、名单和授权说明。本科版从中文封面直接进入授权说明。

| 部分 | 分节与页码 |
| --- | --- |
| 封面、名单、授权说明 | 各部分独立一节。研究生封面按各自页边距设置，本科装订线只用于封面。这些页无章名篇眉与页码；研究生中文封面用独立页眉填写密级，本科用版心顶部的独立表格行。 |
| 摘要至符号和缩略语说明 | 每个章级部分独立一节，从中文摘要以大写罗马数字编号。研究生显示当前部分页眉，本科页眉为空。 |
| 四章示例正文 | 每章独立一节。第 1 章从阿拉伯数字 1 开始，其余章续编。 |
| 参考文献、附录及后置章节 | 每个章级部分独立一节，延续正文页码。两版共用附录示例，专属后置章节由各自内容模块写入。 |

章级分节使用 `nextPage`。单双面、右页起排和装订所需的空白页在打印阶段安排，用户指引见 [打印与装订](../../docs/01-快速入门.md#10-打印与装订)。

## 封面

两版主标题各自在对应的 `cover.py` 中维护。共用院系、作者和导师示例取自 `references/thuthesis/thusetup.tex`，集中在 `src/build/content/cover_example.py`。构建时写入可编辑的内容控件。

封面使用 **无框线单列表格** 固定各块高度；表格仅用于布局，不是内容表格。作者信息单元格固定 6 段，副/联合导师行由“选填信息”菜单中的对应命令增删，删除后保留空行，不改表格行高。

### 中文封面（第 1 节）

研究生封面表格宽 368.5pt，5 行，行高（pt）为 `(130, 142.5, 156, 34.25, 36)`。空白行合并到上方单元格。

| 行 | 内容 | 说明 |
| --- | --- | --- |
| 0 | 论文题目 + 学位申请句 | 从版心顶部（距页顶 6 cm）起排；同格两段，申请句紧接题目，题目可排一行或两行 |
| 1 | spacer | 与第 0 行合并，固定作者信息位置 |
| 2 | 作者信息 | 固定 6 段：培养单位、学科/专业领域、研究生/申请人、指导教师及两行选填导师；删除选填项保留空段落 |
| 3 | spacer | 与第 2 行合并 |
| 4 | 日期 | tag `成文日期`，默认 `二〇二六年十一月` |

两版密级控件 tag 均为 `密级`，默认空白。研究生放在中文封面独立主页眉左侧，16 pt 黑体/Arial，页眉距页顶 2.8 cm；本科放在封面表格首行，行高 18.2 pt，四号（14 pt）黑体/Arial，左对齐，本科所有页眉均为空，封面空白段落恢复内置“页眉”样式（10.5 pt、居中、无下框线）。

DOTM 的“封面 → 选填信息 → 密级信息”在空白时写入 `秘密★5年`，已有文字时删除控件并清空段落；DOCX 可直接编辑控件，研究生需先双击页眉。切换不增删本科密级行、不改变其他部件的位置。研究生官方涉密示例用浮动文本框，ThuThesis 用独立上方区域/本科零高度盒子。本项目按用户要求采用研究生页眉、本科版心独立行。

学位类别为 `dropDownList`，候选按 `configs/degree-options.yaml` 生成，默认“工学硕士学位”。

作者信息单元格内用制表位：右 `159pt`、左 `164pt`，每个条目为制表符 + 标签 + `：` + 制表符 + 内容控件；标签用 `w:fitText` 等宽，4/5/6 字时分别为 1280/1600/1920 twips。

专业学位：把“学科”改为“专业领域”、“研究生”改为“申请人”，学位类别显示“××硕士专业学位”；博士英文学位声明改 `Dissertation submitted to`。

表格宽 391pt，8 行，行高（pt）：


| 行 | 内容 |
| --- | --- |
| 0 | 题目，richText tag `英文论文题目`；20pt Arial 加粗，居中，1.25 倍 |
| 1 | spacer |
| 2 | 5 行学位类型：`Thesis submitted to` / `Tsinghua University` / `in partial fulfillment of the requirement` / `for the degree of` / `Master of Science`，随后为两个独立段落：普通文字 `in`，以及只含学科名称的 tag `英文学科`。两段均固定20pt，不用软换行 |
| 3 | `by` + tag `英文作者`；作者下方 tag `英文专业领域`，仅有专业领域时显示括号领域 |

### 校徽与校名组合

本科封面布局从规则 `cover.chinese.layout` 读取，表格宽 14.8 cm，与版心一致；行高为 `(18.2, 101, 18, 50, 26, 136, 16.5, 156, 47.3, 40)` pt。首行是密级，第二行包含 logo 段前 21 pt；题目区高 136 pt。较上一版，logo、标题和作者信息下移 18.2 pt，日期上方留白缩短 18.2 pt，日期仍约距页顶 680.5 pt。作者信息首段约 473.2 pt，右/左制表位从本科规则读取为 184.5/189.5 pt，抵消表格加宽导致的水平偏移。上页边距仍为 3.8 cm。

本科封面第 1 行以 6.03 × 1.73 cm 直接嵌入现成的 `assets/thu-cover-logo.svg`，并嵌入同一组合图的 `assets/thu-cover-logo.png` 作为兼容版本。

组合图依据《清华大学视觉形象识别系统手册》A-3-03，将 `assets/thu-fig-logo.svg` 的校徽放在左侧，将 `assets/thu-text-logo.svg` 的横式中文标准字放在右侧。以校徽直径的 1/15 为 X，间距为 3X，标准字宽高为 34.3X × 12.6X，底部比校徽底部高 1.4X。

现有 SVG 画布为 171 × 49 bp，直径 49 bp 的校徽从 `(0, 0)` 放置，宽高 112 × 41 bp 的标准字从 `(59, 3.5)` 放置，坐标以画布左上角为原点。PNG 为同一画布的 4 倍分辨率，即 684 × 196 像素。

## 名单与授权

- 答辩委员会名单用 **无框线表格**：3 组（指导小组/公开评阅人 4×3 个 `×××`；答辩委员会 4×4，首列为“主席/委员/委员/秘书”角色），表格居中、宽 15.0cm、无框线，单元格段落套“表格文字”样式并加直接格式 12 pt（指南 2.3.3 要求小四；样式本身是 11 pt，只改名单页、不新增样式）；各组小节标题套“名单页小节标题”样式。
- 授权说明标题必须抑制编号（`numId=0`），否则会继承 Heading 1 的章号，正文变“第 3 章”。
- 授权说明页的签名与日期用**两段纯文本**（`作者签名：＿＿＿　　导师签名：＿＿＿` / `日　　期：＿＿＿　　日　　期：＿＿＿`，套“授权说明文字”样式），不用表格。两变体一致。官方本科样例 `references/official-samples-undergraduate/02 关于论文使用授权的说明.docx` 用的是 2×4 表格，本模板有意统一为纯文本。

## 域

| 位置 | 域 |
| --- | --- |
| 目录（研究生） | `TOC \o "1-3" \t "章标题（无编号）,1,附录标题,1" \h \z \u` |
| 目录（本科） | `TOC \o "1-3" \h \z \u` |
| 插图清单 | `TOC \h \z \c "图"`（Word 内置 `table of figures` 样式） |
| 附表清单 | `TOC \h \z \c "表"`（同上） |
| 图/表题注 | 正文用 `STYLEREF 1 \s` 与 `SEQ 图/表`。附录用 `STYLEREF "附录标题" \s` 与独立的 `SEQ 附录图/附录表`。 |
| 公式 | `#()` 中由 `STYLEREF` 提供章号或附录字母，由 `SEQ 式` 提供组内编号。 |
| 参考文献 | 条目由列表编号，正文引用由 `QUOTE "THU_CITE:..."` 域和条目书签维护。 |
| 页眉 | `STYLEREF 1 \n` + 章标题 |
| 页脚 | `PAGE` |

两版目录标题均从 `documentParts.tableOfContents.heading.style` 取 `chapterTitleUnnumbered`。研究生目录由 `\t` 收录“目录”，页眉用 `STYLEREF "章标题（无编号）"` 取本节标题，续页也显示“目录”。若改回“不进目录”样式，该页眉会向前匹配到 `Abstract`。

本科规则另设 `documentParts.tableOfContents.heading.outlineLevel: bodyText`。生成器只给目录标题段写 `w:outlineLvl=9`，保留共用的标题样式，使 `\u` 跳过该段。摘要、Abstract、两份清单及符号说明继续用“不进目录”样式，目录从正文起收录。

研究生编号章的页眉由章号域、一个全角空格和章名域拼接。全角空格来自章／附录的自动编号，`set_header()` 不再额外插入空格，校验时检查域更新后的结果。附录编号与交叉引用的运行时处理见 [VBA 实现](80-dotm.md#附录编号)。

## 页眉页脚

- 页眉：五号，中文宋体/西文 TNR，居中；内容与该部分章标题相同；各部分首页也要有篇眉。
- 页眉下框线：仅正文/后置页眉，`single 0.75pt`、`space=1`；封面、名单、授权、空白页眉不加；页脚无框线。
- 页码：前置罗马数字（从摘要开始），正文阿拉伯数字；页脚居中 TNR 五号，无修饰线。
- 页码位置：页脚距页面底边 `1.5cm`（`pageSetup.defaultPageMargins.footer`），页码字符底端距页底约 1.9cm、基线约 2.0cm。
- 页码续接：新节必须 `set_pgnum(sec, "decimal")`，不要带 `start`；否则会继承 `start=1` 重排。

## 章间分节

- 所有章级标题前调用 `src/build_docx.py:chapter_section(...)`；它执行 `doc.add_section(WD_SECTION.NEW_PAGE)`，再按 `pageSetup` 规则设置页边距、页眉页脚距离和页码（默认值读 `defaultPageMargins`，封面读 `pageSetup.sections.*.pageMargins`，生成脚本不写死数值）。
- 分节符直接插入，不额外设置自带空段落的字体、字号、行距或段距。
- 章标题样式（`Heading 1`、`章标题（无编号）`、`章标题（无编号、不进目录）`、`附录标题`）全部 `pageBreakBefore=false`。
- 不要用普通分页符代替章间分节符，也不要只给某一个章标题样式设“段前分页”。
