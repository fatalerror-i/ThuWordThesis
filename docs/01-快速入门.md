# 快速入门

在 Windows 桌面版 Word 中用 DOTM 新建论文，再从“论文”选项卡排版。两版的常用按钮用法一致，两版均有封面选填按钮，研究生版还提供学位与日期联动，两版的后置章节按论文类型选择。

- 第一次使用请从[打开与启用宏](#1-打开与启用宏)开始。
- 写作时可查[封面](#3-封面)、[公式](#4-公式)、[图表题注](#5-图注表注子图注)和[参考文献引用](#6-参考文献引用)。
- 定稿前依次[更新域与导出](#9-更新域)，再核对[打印与装订](#10-打印与装订)。

## 1. 打开与启用宏

1. 把对应的 DOTM 放在固定位置。在 Windows 资源管理器中双击模板，新建文档。
2. 保持宏禁用，将新文档保存为 `我的论文.docx`。关闭并重新打开这份 DOCX。
3. 如重开时提示“该工程中的宏被禁止”，先关闭对话框。确认模板来源可信后，如有黄色安全提示，单击“启用内容”。Word 从关联模板加载“论文”选项卡，后续编辑在这份 DOCX 中进行。

如果“论文”选项卡未出现或出现两次，见[常见问题](03-常见问题.md#没有按钮或按钮不完整)。

**让论文使用新版模板**

1. 保存论文并关闭 Word，用同一类型的新版 `.dotm` 替换原位置的模板文件，保留原文件名。重新打开论文，Word 会加载新版模板的宏。如果新版文件改名或放在其他位置，在论文中选择“开发工具 → 文档模板 → 选用”，选中新文件后保存。
2. 如果要同步新版样式，在“文档模板”对话框勾选“自动更新文档样式”，保存论文并重新打开。若只更新宏或修复模板路径，让此项保持未勾选。
3. 核对目录、标题、题注和页眉页脚。样式同步会更新样式定义，已有封面和分节结构需要按新版要求单独核对。若只想同步这一次，核对后取消勾选“自动更新文档样式”并保存。

如果旧写作稿已经内嵌宏，更换关联模板后，原有的 VBA 仍保存在旧稿中。

如果没有看到“开发工具”选项卡，在“文件 → 选项 → 自定义功能区”的“主选项卡”列表中勾选“开发工具”。[微软的操作说明](https://support.microsoft.com/zh-cn/word/show-the-developer-tab-in-word)

章、节和附录的自动编号自带一个全角空格，直接套用标题样式即可，无需在标题文字前手动加空格。

## 2. 功能区一览

“开始”选项卡的样式库可直接选用正文、标题、图表、公式、文献引用和列表等常用样式。要找封面、目录或其他模板样式，打开“开始 → 样式”组右下角的样式窗格，在“选项”中将显示范围和排序方式都设为“推荐”。三线表样式在选中表格后的“表格设计”中查看。

两版“论文”选项卡均有 11 组。

| 组 | 按钮 / 菜单 | 行为 |
| --- | --- | --- |
| 封面 | 选填信息；研究生另有刷新封面 | 两版均可增删密级信息；研究生还可刷新学位与日期，增删副导师、联合导师。详见[封面](#3-封面)。 |
| 段落 | 正文章节 | 下拉选择章标题或 1–3 级节标题，把当前段落设为对应标题格式 |
| 段落 | 附录章节 | 下拉选择附录标题或附录 1–3 级节标题 |
| 段落 | 其他章节 | 下拉选择“章标题”或“章内无编号小节”；章标题再选摘要、Abstract、目录、插图清单、附表清单、符号说明、参考文献、致谢、声明及该变体的专属后置章节 |
| 段落 | 正文 | 把光标所在段落或选中的多个段落设为“正文”样式 |
| 字体 | 强调 | 下拉选择“不明显强调 / 强调 / 明显强调”，对选中文字套用对应字符样式 |
| 列表 | 有序列表 | 下拉选择 `1.`、`(1)`、`a.` 三种列表编号，套用模板样式 |
| 列表 | 无序列表 | 下拉选择 `•`、`◦`、`*` 三种项目符号，套用模板样式 |
| 列表 | 调整编号 / 参考文献 / 缩略语 | “调整编号”下拉：继续编号（接续上方列表编号）、重新开始于1；参考文献下拉选择“顺序编码制”或“著者出版年制”；“缩略语”将当前行整理为“缩略语 + 制表符 + 说明”并套“符号说明条目”样式 |
| 图片 | 插入图片 / 图注 / 子图注 | 插入嵌入型图片并套“图片”样式；为选中文字、当前段落或空白行添加图注；为分图添加 `(a)`、`(b)` 子图注；如需使某条子图注重新从 (a) 开始，选中该子图注后单击“列表→调整编号→重新开始于1” |
| 表格 | 插入表格 / 表注 | 插入三线表；给选中文字、当前段落或空白行加表注；跨页时重复表头 |
| 公式 | 行内公式 / 行间公式 | 行内按钮插入或调整行内公式；行间公式下拉菜单：有编号时插入并自动编号，无编号时仅套用“公式”样式 |
| 代码 | 行内代码 / 行间代码 | 选中文字套“行内代码”；整段套“行间代码”并自动编号 |
| 引用 | 引用内容 / 引用文献 / 脚注 / 更新域 | 插入图/表/公式/章节交叉引用；引用参考文献；在光标处插入脚注；更新全部域 |
| 导出 | 导出 | 下拉选择“导出为 DOCX”或“导出为 PDF” |
| 帮助 | 关于 | 查看模板简介与版本 |

单击“引用 → 引用检查”。在对话框中切换“图注（含子图注）”“表注”“引用”和“未引用提示”选项卡，可查看和复制各类问题。图注和表注检查正文与附录的图片、表格是否配有题注，以及编号域和书签是否齐全。引用检查会核对书签、文档属性和文献条目。未引用的图表题注只作提示。检查过程只读，建议先单击“引用 → 更新域”，再查看结果。

## 3. 封面

封面已填入示例题目和作者信息。新建写作稿后，直接在对应控件中替换为自己的论文信息。

**本科版**在封面上填写题目、系别、专业、姓名、指导教师和成文日期。

**研究生版**直接在中英文封面填写：

1. 先选学位类别，再选学科或输入学科名称。确认学位选项后，中英文提交声明、学位名称和导师称谓自动同步。专业学位显示“申请人”，设置专业领域的类别另显示“专业领域”；切换硕博保留已填的作者和导师信息。
   学位门类与学科名称按指南附录C、D整理，跨门类授予学位的学科会出现在相应候选中。交叉学科按实际授予的学位门类选择。专业领域由所属院系确认后手填；附录G的旧工程硕士领域不作为现行专业领域候选。已有输入会保留，切换类别后请核对。
2. 填写题目、培养单位、作者及导师。若有副导师或联合导师，通过“封面 → 选填信息”添加对应行。新增行固定排在作者信息下方，副导师在联合导师之前，无需先移动光标。再次点同一项会删除该行和已填内容，两行分别与英文封面的 `Associate Supervisor`、`Co-supervisor` 同步，英文姓名另行填写。
3. 密级填写方式与本科版相同，见下方说明。
4. 用 `2026-11` 这样的年月格式输入成文日期，可同时生成中英文日期。直接填写含“年”的中文日期时，请另行核对英文日期。
5. 学术学位在英文封面的 `in` 下填写英文学科。`in` 是独立段落中的普通文字，只替换下一段控件内的学科名称。设置专业领域的专业学位在作者姓名下填写括号内的英文领域名称。切换学位类型会保留这两类已填内容，恢复相应类型时重新显示。
6. 最后核对中英文封面上的姓名、学位、导师和日期。需要重新计算学位相关内容时，单击“封面 → 刷新封面”。

本科密级在封面版心顶部的独立表格行，研究生密级在中文封面页眉左侧，公开论文均留空。单击“封面 → 选填信息 → 密级信息”写入示例 `秘密★5年`，再次单击清空。DOCX 可直接编辑对应控件；研究生需先双击封面页眉。本科密级行始终保留，填写或清空均不移动其他部件；密级不出现在后续页面。研究生版同时切换公开／涉密声明中的保密表述，提交前请核对学校原文。

字号、行距和位置见[格式定义](02-格式定义.md#封面)。

## 4. 公式

公式分两个按钮，**均不显示消息对话框**：行内公式；行间公式在下拉菜单中选择“有编号”或“无编号”：

### 4.1 行内公式

- 光标在文字行内且未选中文字：在光标处插入行内公式占位符 `□`，并套用“行内公式”字符样式（XITS Math 12pt）。
- 选中一段文字后单击：将选中文字转换为行内公式，保留原文，不再插入占位符。
- 光标已在行内公式内：仅将该公式调整为“行内公式”字符样式，不改变编号或段落。
- 光标在空白行或行间公式内：自动转为“行间公式”处理。

### 4.2 行间公式

单击“公式 → 行间公式”，在下拉菜单中选择：

**有编号**（需要编号或引用时使用）：

- 光标在空白行：插入带占位符和编号的空白行间公式。
- 光标已有行间公式：应用“公式”样式并自动编号，或规范化已有编号。
- 光标在文字行内：在当前段之后新建一段，再插入行间公式。
- 光标在无编号公式上：清除无编号状态并生成编号。

有编号公式的宏执行以下操作：

1. 套用“公式”样式（居中、段前后 6 磅、单倍行距）；
2. 删除旧的 `#(...)` 或手工编号；
3. 在公式尾部生成 `#(章.序号)`：正文 `(2.1)`，附录 `(A.1)`；
4. 给公式编号建立书签，供引用；
5. 重复单击不会叠加编号。

**无编号**（只排版、不引用时用）：

- 仅套用“公式”样式并居中，不生成编号和书签。
- 公式仍为显示公式，但不含编号，因此不进入编号刷新与“引用公式”列表。
- 光标在已有无编号公式上再次单击：保持无编号。
- 光标在有编号公式上单击：删除编号和书签，转为无编号。

**引用公式**：将光标置于引用处，单击“引用 → 引用内容 → 公式”，在列表中选取，得到 `式(2.1)`。列表仅显示有编号的公式，不显示无编号公式。公式引用的结果字体为 XITS Math；编号变化后更新域即可自动更新。

**插入新公式后的编号变化**：新公式立即得到正确编号。若新公式插在已有公式之前，后续公式的序号会变，但其显示编号不会立即改变；单击“引用 → 更新域”后统一刷新。打开“引用公式”列表时，宏会先刷新编号，因此列表显示当前值。

注意：

- 公式必须是 Word 自带公式（OMML，Alt+= 插入），请勿使用旧式 Equation 3.0 对象或图片。
- 编号依赖“公式”样式和章标题；移动公式后单击“更新域”。
- 如果编号显示为域代码，按 `Alt+F9` 切换显示。

## 5. 图注、表注、子图注

- **图注**：将光标置于图片所在段落或空白行，单击“图片 → 图注”；存在选中文字/当前段文字时采用该文字，否则自动填入占位“图题”。宏在图片下方或当前空白行插入 `图2.1　题名`。
- **表注**：选中表题文字、将光标置于表格内或空白行，单击“表格 → 表注”；存在文字时采用该文字，否则自动填入占位“表题”。宏在**整个表格上方**或当前空白行插入 `表2.1　题名`，不会写入单元格，也不显示输入对话框。
- **子图注**：将光标置于分图所在段落或空白行，单击“图片 → 子图注”，宏在该图后或当前空白行插入 `(a)　分图题名`；字母编号自动递增，不带主图号，也不进插图清单。编号固定为 `(a) (b) (c)`；如需使某条子图注重新从 (a) 开始，选中该子图注后单击“列表→调整编号→重新开始于1”。分图题名采用选中文字/当前段文字，空白时自动填入“子图题”；套用“子图注”样式，视觉格式与“图注”一致。

约定：

- 标签与编号之间没有空格：`图2.1`，不是 `图 2.1`。
- 编号与题名之间是一个全角空格 `　`。
- 附录中的图表自动使用 `图A.1` / `表A.1`，并套用“附录图注/附录表注”样式；插图清单和附表清单仅收录正文的图注、表注；附录题注使用独立编号，因此不进入清单。
- 插入后若编号显示为 `0` 或空白，单击“更新域”。

**引用图/表**：单击“引用 → 引用内容 → 图/表”，在列表中选取图注或表注，得到 `图2.1` / `表2.1`。已有题注但没有书签时，宏会自动补建书签，不再提示“找不到表题注”。

**引用章节**：单击“引用 → 引用内容 → 章节”，列表包含“章标题（有编号）”“一级节标题”“二级节标题”“三级节标题”“附录标题”和附录一至三级节标题。插入的是指向该标题段落的编号引用（与 Word 原生交叉引用同一机制）；标题编号变化后，单击“更新域”即可刷新。

**引用公式**：模板中已有编号的公式也可直接引用；首次打开时宏会为公式编号补建书签。

**引用与书签**：图、表、公式和章节的交叉引用采用显式书签：

- 宏在题注编号和章节标题处建立书签；
- 引用时插入指向书签的编号域；
- Word 原生“交叉引用”会建立隐藏书签；本模板不依赖这些书签，复制、合并或重建文档后仍可由宏补建；
- 显式书签会出现在 Word 的“书签”对话框中，不需要手工管理。

**脚注**：将光标置于正文中需添加脚注的位置，单击“引用 → 脚注”，Word 会在该处插入脚注标记，光标进入脚注区，直接输入脚注文字即可。脚注编号按模板的脚注设置自动编排；脚注文本中的编号为普通文本，正文中的脚注标记保持上标。脚注文本左缩进 0 字符、续行悬挂缩进 1.5 字符，段前段后 0 磅；宏会在脚注编号后补一个半角空格，使编号与文字隔开。

## 6. 参考文献引用

1. 先将参考文献整理为参考文献条目样式。模板支持两种著录体系：
   - **顺序编码制**：套“参考文献条目”样式，编号由模板的 `[%1]` 列表负责；
   - **著者出版年制**：套“参考文献条目（著者出版年）”样式，不编号，保留与顺序编码制相同的字号、行距和悬挂缩进 1 厘米。
   在“列表 → 参考文献”下拉菜单中选择对应格式即可。
2. 将光标置于正文引用处，单击“引用 → 引用文献”。
3. 窗口列出**全部**文献条目，可选取多条；可拖动窗口边框调整大小（最大 880×640 磅），条目较多时使用列表右侧滚动条查看。
4. 单击“确定”后将这些文献合并为一个引用：连续序号压缩为区间，例如选取第 2、3 条得到 `[2-3]`，选取第 7、9、11、12、13 条得到 `[7, 9, 11-13]`；整段套用“文献引用”字符样式（上标、Times New Roman/宋体）。

说明：

- 按参考文献表顺序编号；多选时自动排序、去重并合并连续区间，不显示引文页码。
- 引用编号通过条目书签维护；条目顺序变化后单击“更新域”，正文编号随之重算。
- 参考文献增删或重排后，单击“引用 → 更新域”刷新上标序号。普通 F9 保留最近一次显示的文献编号。
- 如果原条目被删除或不再是参考文献条目，更新后会显示“引用失效”，“引用检查”也会报告该项。请重新选择正确的条目。
- 若编号未更新，先单击“更新域”，再检查条目是否均采用“参考文献条目”样式。

## 7. 段落：章节、附录、其他部分

- **正文章节**：将光标置于新章起始位置，从“段落 → 正文章节”选择“章标题”或 1–3 级节标题；宏将当前段落设为对应样式，编号由样式自动生成。新章需要另起一节时，先在标题前插入“布局 → 分隔符 → 下一页”分节符。
- **附录章节**：从“段落 → 附录章节”选择附录标题或附录 1–3 级节标题；按 A、B、C 自动编号。
- **其他章节**：从“段落 → 其他章节”下拉选择“章标题”或“章内无编号小节”。
  - 章标题：再选择摘要、Abstract、目录、参考文献、致谢、声明及该变体的专属后置章节，套用对应章标题。
  - 章内无编号小节：插入无编号、无大纲级别、居中的小节标题，适用于个人简历章中的“个人简历”“在学期间完成的相关学术成果”等小标题。

请勿手写“第 1 章”“附录 A”；编号由标题样式维护。

## 8. 列表

有序列表提供三种样式，编号格式分别是 `1.`、`(1)`、`a.`；无序列表提供三种项目符号：`•`、`◦`、`*`。列表会随层级设置缩进和编号位置，具体数值见[格式定义](02-格式定义.md#正文列表与代码)。将光标置于列表段落，或选中多个列表段落，单击“列表 → 有序列表/无序列表”中的对应项即可一次性套用该列表样式；编号由模板样式维护，请勿手工输入。

- **继续编号**：选中需接续上方编号的列表段落，单击“列表 → 调整编号 → 继续编号”；宏按同一列表模板将编号接续至上方列表，等价于 Word 的“继续编号”，并保持原有缩进。
- **重新开始于1**：选中已有列表段落，单击“列表 → 调整编号 → 重新开始于1”；宏将编号重置为 1，并重新套用原列表样式，修复 Word 手动“重新开始于1”造成的字体/缩进变化。
- **缩略语**：在“符号和缩略语说明”一章中，将光标置于目标行，单击“列表 → 缩略语”。空行会写入“缩略语 + 制表符 + 说明”；行内已有文字但不含制表符时，会补充制表符和“说明”；已有制表符时仅套用“符号说明条目”样式。随后将“缩略语”和“说明”替换为实际内容。说明列固定在 12 字符（约 5.08 厘米）处，续行文字与说明列对齐。
- **参考文献**：选中参考文献段落，单击“列表 → 参考文献”，在下拉菜单中选择：
  - **顺序编码制**：转换为“参考文献条目”样式，编号自动为 `[1]`、`[2]`；
  - **著者出版年制**：转换为“参考文献条目（著者出版年）”样式，不显示编号，保留悬挂缩进 1 厘米。

### 8.1 代码

- **行内代码**：选中文字后单击“代码 → 行内代码”，套用“行内代码”字符样式（仿宋 + Consolas，不改变段落间距）；未选中时插入占位 `Hello World!`。
- **行间代码**：将光标置于段落内，单击“代码 → 行间代码”，整段套用“行间代码”样式（仿宋 + Consolas、单倍行距、左对齐、自动行号）；空段会写入 `Hello World!`。
- 行间代码的行号由模板编号维护，请勿手写行号。

## 9. 更新域

插入/移动公式、题注、文献后，单击“引用 → 更新域”，宏会更新正文、页眉页脚、目录、插图清单、附表清单和文献引用编号。在已有公式之前插入新公式时，旧公式的编号不会立刻改变，亦由该步骤统一刷新。

如果附录说明中的 `图A.1`、`表A.1`、`式(A.1)` 显示“错误!未定义书签”，单击一次“引用 → 更新域”即可；宏会重写损坏的编号复位域，清除错误结果。

### 9.1 导出提交版

保存写作稿，在“论文”选项卡的“导出”组单击“导出”。选择所需格式后，文件会写入写作稿所在文件夹。若目标文件已存在，Word 会询问是否覆盖。

- **导出为 DOCX** 生成“原文件名_提交版.docx”。提交版会解除论文模板的关联、移除文档内嵌的功能区，并固定导出时的文献编号。目录和图表题注仍可更新。
- **导出为 PDF** 生成“原文件名.pdf”。导出前会在副本里更新目录、题注和文献引用。

## 10. 打印与装订

- **研究生论文**：中文封面、英文封面、名单和授权说明单面打印，从中文摘要起双面打印。
- **本科综合论文训练论文**：封面和授权说明单面打印，从中文摘要起双面打印。
- 两类论文的正文按写作指南或规范从右页开始。套用模板后，由作者按院系要求在打印或装订阶段设置单双面、安排右页起排及所需空白页。打印前按 PDF 的实际页序核对打印范围，并确认摘要和正文的页码起点。
