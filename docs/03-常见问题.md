# 常见问题

使用宏功能时，先确认在 Windows 桌面版 Word 中打开了宏模板或写作稿，并已启用宏。

## 没有按钮或按钮不完整

| 现象 | 处理 |
| --- | --- |
| 没有“论文”选项卡 | 在“开发工具 → 文档模板”中确认写作稿关联了正确的 `.dotm`。确认来源可信后，如果看到黄色安全提示，单击“启用内容”。单位计算机统一禁用宏时，联系管理员或使用不带宏的 `.docx` 模板手工排版。 |
| 出现两个“论文”选项卡 | 如果在首次保存前启用了宏，写作稿可能同时保存了功能区和模板关联。新建时按[首次打开步骤](01-快速入门.md#1-打开与启用宏)先保存并重开写作稿，再启用宏。 |
| 在 WPS 或 Mac 上按钮不全 | WPS 免费版通常不支持模板中的自动按钮；Mac 版 Word 对宏窗体（如文献引用窗口）的支持也有限。如需完整按钮，请使用 Windows 版 Microsoft Word。 |
| 模板更新后如何让论文使用新版 | 在原位置替换模板并重新打开论文。新版放在其他位置时，在“开发工具 → 文档模板 → 选用”中选中新文件并保存。需要同步样式时再勾选“自动更新文档样式”。详见[快速入门](01-快速入门.md#1-打开与启用宏)。 |
| 功能区按钮单击后无响应 | 先确认写作稿仍关联对应模板，并检查 Word 的宏提示。若按钮报错，记下错误信息并重新打开写作稿重试。 |

## 编号与域

| 现象 | 处理 |
| --- | --- |
| 目录、题注、公式编号没有变化 | 单击“引用 → 更新域”。插入新公式后，后续公式的序号须待该步骤方可刷新。 |
| 编号显示成域代码（如 `SEQ 图`） | 按 `Alt+F9` 切换域代码显示。 |
| 编号显示 `0` 或空白 | 单击“更新域”；确认所在段落套用对应样式（“图注”“表注”“公式”）。 |
| 附录显示“错误!未定义书签” | 单击一次“更新域”。宏会重写损坏的编号复位域。 |
| 旧稿的文献引用显示内部代码 | 使用新版模板的“引用 → 更新域”刷新，再用“导出为 DOCX”生成提交版。已有的旧版提交文件需从写作稿重新导出。 |
| 文献引用显示“引用失效” | 原文献条目已删除或变更样式。使用“引用检查”核对，并重新选择正确的文献条目。 |
| 交叉引用提示找不到表题注 | 题注已存在但无书签时，宏会自动补建；仍失败则先“更新域”，再重试引用。 |

## 封面

| 现象 | 处理 |
| --- | --- |
| 英文学位名称、英文日期未随之更新 | 启用宏后，单击“封面 → 刷新封面”重算派生字段。无宏文档可手工填写。 |
| 副导师行无法删除 | 该命令按内容控件存在性进行切换：控件不存在时为新增，存在时为删除。确认光标所在文档已启用宏。 |
| 密级如何填写或清空 | 本科在封面版心顶部独立行，研究生在封面页眉左侧。可用“封面 → 选填信息 → 密级信息”切换，或直接编辑控件；研究生需先双击页眉。空白表示公开，切换不影响其他部件的位置。 |

## 排版与样式

| 现象 | 处理 |
| --- | --- |
| 列表缩进异常 | 通过“列表 → 调整编号 → 重新开始于1”，宏会重新套用样式并修复 Word 更改后的缩进偏差；请勿手工拖动标尺。 |
| 表格跨页后没有表头 | 模板的三线表已设“标题行重复”；若手工插入的表格未设置，选中表头行 → 表格工具 → 布局 → 重复标题行。 |
| 图片标注文字字号不一致 | 图内标注属于写作内容，模板不规定；建议 9–10.5 pt 与正文字号协调。 |
| 中文引号显示为直引号 | 须以中文全角引号“”，模板已设中文字体渲染；请勿使用 ASCII 直引号。 |
| 旧稿换用新版模板后仍未自动断字 | 文档级开关需在旧稿中设置：进入“布局 → 断字 → 断字选项”，开启自动断字，连续断字上限设为2，并关闭全大写单词断字。 |
| 英文单词在行尾出现连字符 | 模板默认开启自动断字；行间代码、公式与参考文献样式关闭。可在“布局 → 断字”查看文档设置，在“修改样式 → 格式 → 段落 → 换行和分页”查看“取消断字”。 |
| 正文里出现多余空格 | 模板要求不在中文与西文之间手工加空格，Word 会按字体自动调整间距。 |

## 模板未做

- 不生成续表题注，也不提供续表按钮。Word 跨页表格可以保留同一张表并重复表头。
- 不生成书脊，请在打印时移交处理。
- 不做本科生综合论文训练记录表。

## 限制

- 宏默认禁用，用户需“启用内容”或将模板置于受信任位置；组策略可能完全禁止。
- 研究生封面的学位和日期联动由文档事件驱动，需要启用宏。
- WPS 免费版通常无 VBA；Mac Word 对 VBA 窗体支持有限。无宏时仍可手工填写内容控件、手工套样式。
- 提交版使用“导出 → 导出”生成，支持 DOCX 和 PDF。
- “引用”组的“引用检查”按钮（研究生与本科两个变体都有）运行只读宏 `src/dotm/vba/modCheck.bas`（图表配对检查只覆盖正文与附录，封面、目录、名单页等前置部分不参与）：检查图片是否有对应的图注/子图注、表格是否有对应的表注，且题注以域格式存在（含 `SEQ`/`REF` 域与 `THU_*` 书签）；检查图表题注是否被正文引用（未被引用者单独列为“未引用”提示分组，不计入硬错误；检查按显式引用统计，仅写“表4.2至表4.4”时，表4.3仍会显示为未引用）；检查交叉引用和文献引用的目标是否仍然存在（含书签、自定义属性和文献条目）。结果用一个弹窗列出。宏只读、不更新域、不写文档；先单击“引用 → 更新域”再检查，`REF` 结果文字才准确。封面内容控件、公式编号、题注文字格式、编号重复、必备样式、字数等内容项以及字号、行距、段距、页眉页码不检查。
- 英文题注（中英文对照）尚未实现，见 `TODO.md`。
- 模板不规定书脊、正文右页起章、单双面印刷、综合论文训练记录表，也不校验论文题目字数、摘要字数与篇幅。这些属打印或写作范畴，由作者与院系安排。
- 模板与官方指南的差异及处理方法见[与写作指南的差异](02-格式定义.md#与写作指南的差异)。
